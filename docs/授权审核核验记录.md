### 3.2 数字复算路径

```

  计算方式：matched_chars(500) / total_tender_chars(888) * 100 = 56.3%

AI 调整后 33.8%（e6bc128 代码，300 字符截断口径）

  计算方式：完整段落 AI 分类，全部判定为合规应答
  说明：截断修复后 LLM 看到完整技术参数，分类更准确

最终采用 12.0%
  计算方式：actual_dup_chars(107) / total_tender_chars(888) * 100 = 12.0%
  人工修正：4 处修正，共 107 字符实际重复
  记录文件：samples/output/human_correction.json
  核验结论：数字可独立复算，与真实项目评标记录一致
```

### 6.2 编号映射方法

脱敏编号格式为 CT-YYYY-XX-NNNN，其中年份和序号后四位与真实编号一致。授权材料评审人可通过公司内部项目管理系统，使用脱敏编号中的年份+类型+序号进行模糊搜索，匹配项目名称和日期后获取完整信息。详见 [脱敏业务采用说明 4.2 节](脱敏业务采用说明.md#42-脱敏编号映射方法)。
