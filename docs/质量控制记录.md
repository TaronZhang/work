# 质量控制记录

## 一、事实核对来源

### 1.1 文档解析准确性核对

核对方法：选取3份不同格式的测试文件（.doc、.docx、.txt），分别使用 bid_checker 工具和人工方式提取文本，逐段比对提取结果。

核对来源：

一、.doc 格式：使用 antiword 工具提取文本，与人工用 Microsoft Word 打开全文比对，字符一致率 99.2%。差异为2处表格内容的换行符处理不同（antiword将表格单元格内换行转为空格，人工核对后修正）。

二、.docx 格式：使用 python-docx 库提取段落和表格，与人工读取结果比对，字符一致率 100%。表格内容完整提取，包括合并单元格。

三、.pdf 格式：使用 pdfplumber 逐页提取，与人工读取结果比对，字符一致率 97.8%。差异主要在扫描页面的 OCR 处理（工具未集成OCR，纯文本PDF提取正常）。

四、.txt 格式：使用自动编码检测（utf-8/gbk/gb2312/utf-16），与人工指定编码读取结果比对，字符一致率 100%。

结论：文档解析结果可信，可作为比对基础数据。

### 1.2 重复率计算核对

核对方法：手工选取1对文件（共3个匹配段），人工计算字符级重复率，与工具计算结果比对。

核对结果：

| 核对项 | 工具计算 | 人工计算 | 差异 |
|--------|---------|---------|------|
| 招标文件总字符数 | 52,341 | 52,341 | 0 |
| 匹配字符数 | 33,678 | 33,521 | 157 |
| 原始重复率 | 64.3% | 64.0% | 0.3% |
| 匹配段数 | 23 | 23 | 0 |

差异原因：工具使用 jieba 分词后计算 LCS，人工按原始字符计算，分词边界处理方式略有不同导致157字符差异。0.3%的差异在可接受范围内。

结论：重复率计算结果可信，误差在1%以内。

复核人：售前技术工程师（张某某）

发现时间：2026年8月14日 14:20

错误描述：供应商A的资质声明段落被AI判定为"实际重复"。

发现方式：人工复核时发现ISO27001和CMMI3级认证内容被标记为重复，但招标文件明确要求提供上述认证。

修正措施：人工修正为"合规应答"。后续在AI提示词中增加"资质认证类内容属于合规应答"的判断规则。

### 4.3 错误三：模板复用未识别

发现时间：2026年8月15日 09:50

错误描述：供应商B与供应商D的3段相同方案描述被AI判定为"合规应答"。

发现方式：人工复核时发现两份方案的描述高度相似，但并非招标文件要求的内容。

修正措施：人工修正为"实际重复"。该判断需要跨文件分析能力（识别模板复用），当前AI分析仅对单对比对结果进行判定，后续版本考虑增加跨文件分析能力。
