### 4.2 脱敏编号映射方法

所有脱敏编号格式为 `CT-YYYY-XX-NNNN`，其中：
- CT：长亭科技内部编号前缀（固定）
- YYYY：年份（与真实项目一致）
- XX：业务类型代码（SW=网络安全项目，WO=工单，EVAL=评标）
- NNNN：序号（与真实编号后四位一致）

授权材料评审人可通过以下方式映射到真实编号：
1. 访问公司内部项目管理系统
2. 使用脱敏编号中的年份+类型+序号后四位进行模糊搜索
3. 匹配项目名称和日期后获取完整信息
4. 如遇困难，联系解决方案中心运营人员协助

### 4.3 交叉验证方法

材料评审人可通过以下方式交叉验证业务真实性：
1. **仓库内自证**：samples/output/ 全部报告 + run_record.md + human_correction.json，数字可复算
2. **代码可复现**：使用相同输入文件和代码版本，运行 `bid-checker compare` 命令可得到相同结果
3. **LLM调用可验证**：llm_call_record.json 记录了调用时间和模型，与公司 AI Gateway 日志可对应
4. **工单可核验**：CT-WO-2026-0814-003 在内部工单系统可查
5. **评标可追溯**：CT-2026-EVAL-0816 在评标档案系统可查
