## 三、数据安全与合规

### 3.1 投标文件数据安全

一、投标文件属于商业敏感数据，工具运行时不上传文件至外部服务，仅在本地/Docker容器内解析处理

二、文件解析和比对在 Docker 沙箱内执行，与宿主系统隔离

三、LLM 调用仅发送文本段落片段（每批10-15段），不发送完整文档，减少敏感数据暴露

四、agent-compose 模式下，LLM 请求通过 daemon facade 代理转发，API Key 由 daemon 统一管理，沙箱内不存储密钥

### 3.2 报告数据安全

一、生成的报告文件存储在 /workspace/reports/ 目录，仅在 Docker 沙箱内可访问

二、独立网页模式下，上传文件使用 UUID 命名，不含原始路径信息

三、比对完成后可手动清除所有文件和缓存
