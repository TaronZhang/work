# techtoexcel 使用说明

## 快速上手

```
/techtoexcel <招标文件路径.docx/.doc> <章节名> <输出路径.xlsx>
```

示例：
```
/techtoexcel d:\项目\招标文件.docx "第三章 采购需求" d:\项目\技术偏离表.xlsx
/techtoexcel d:\项目\招标文件.doc "六、招标内容与要求" d:\项目\技术偏离表.xlsx
```

## 技能做了什么

1. **自动格式转换** → 检测文件格式，.doc自动转换为.docx（需安装Word）
2. 读取招标文件段落和表格
3. 提取指定章节的全部内容
4. 展示结构概览，**等你确认**后再继续
5. 按规则生成四列技术偏离表
6. 输出 Excel，展示预览

## 支持的文件格式

| 格式 | 支持状态 | 说明 |
|------|----------|------|
| .docx | ✅ 直接支持 | Word 2007+ 格式 |
| .doc | ✅ 自动转换 | Word 97-2003 格式，需安装 pywin32 和 Microsoft Word |

## 依赖安装

```bash
# 必需依赖
pip install python-docx openpyxl

# .doc格式转换支持（可选）
pip install pywin32
```

## 输出表格

| 列 | 含义 |
|----|------|
| 序号 | 从1递增 |
| 招标文件技术条款 | 原文一字不改 |
| 投标文件技术条款 | 应答：完全满足且无偏离。+ 点对点 |
| 偏离说明 | 全部无偏离 |

## 交互确认环节

技能会在以下情况暂停并询问你：
- 章节边界在哪
- "以下"合并该合并多少
- 哪些内容跳过
- 不确定的拆分/合并

## 你的反馈直接驱动迭代

每次输出 v1.xlsx 后，你可以说：
- "第X条目应该合并到第Y条目"
- "星号规则不对，修正"
- "措辞需要再调整"

技能会按照你的反馈修正并输出新版本。
