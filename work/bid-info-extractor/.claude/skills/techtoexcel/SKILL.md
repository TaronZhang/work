# techtoexcel — 技术偏离表生成

## 调用方式

```
/techtoexcel <招标文件路径> <目标章节> <输出路径>
```

## 输出格式 (4列)

| 列 | 列宽 | 内容规则 |
|----|------|---------|
| A 序号 | 8 | 从 1 递增 |
| B 招标文件技术条款 | 70 | 原文完整复制，一字不改 |
| C 投标文件技术条款 | 70 | `应答:完全满足且无偏离.我司按照招标要求提供服务.{清洗后原文}` |
| D 偏离说明 | 15 | 全部"无偏离" |

---

## 数据处理规则

### 一、表格处理 (程序化，不经过 LLM)

1. 读取 docx 中所有表格
2. 第一行 = 字段名/表头
3. 之后每行 = 一条目
4. **B 列** → `字段1：值1, 字段2：值2, ...`（逗号+空格分隔）
5. **示例**:
   - 表格行: `[网络攻防红蓝军演训服务, 公开招标, 278.6万元]`
   - B列: `项目名称：网络攻防红蓝军演训服务, 采购方式：公开招标, 项目预算：278.6万元`
   - C列: `应答:完全满足且无偏离.我司按照招标要求提供服务.项目名称：网络攻防红蓝军演训服务, 采购方式：公开招标, 项目预算：278.6万元`

### 二、段落处理 (LLM 拆条)

1. 每个独立需求点 = 一条目
2. 编号列表 (1. 2. 或 a) b) 或 (1)(2)) → 各自成条
3. "以下"/"如下"/"包括" 开头 → 后续子项合并为一条
4. 纯标题无内容 → 跳过
5. 备注/说明/注 → 跳过
6. **B 列必须完整包含原文，不得截断**

### 三、C 列措辞清洗

| 原文 | 替换 |
|------|------|
| ★ | (删除) |
| 投标人 | 我司 |
| 包括但不限于 | 包括 |
| 不少于 N 年 | N 年 |
| 至少 N 个 | N 个 |
| 要求具有 | 具有 |
| 要求具备 | 具备 |

### 四、约束

- **表格一行 = Excel 一行**，不得将多行合并
- B 列原文保留 ★ 星号
- C 列应答不得为空，强制生成
- 长段落完整保留，不得截断省略
- 生成后自动验证 C 列残留问题

## 依赖

- python-docx, openpyxl
- pywin32 (可选, .doc → .docx 转换)
