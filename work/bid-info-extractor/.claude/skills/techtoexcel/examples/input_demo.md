# techtoexcel 示例

## 输入

```
/techtoexcel d:\招标文件.docx "第三章 采购需求" d:\技术偏离表.xlsx
```

## 预期输出

生成 Excel 文件，结构如下：

| 序号 | 招标文件技术条款 | 投标文件技术条款 | 偏离说明 |
|------|-----------------|-----------------|---------|
| 1 | 第三章采购需求\n一、需求一览表\n采购内容：... | 应答：完全满足且无偏离。我司提供... | 无偏离 |
| 2 | ... | ... | 无偏离 |
| ... | ... | ... | 无偏离 |
