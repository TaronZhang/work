## 一、系统简介

**Bid Info Extractor** 是一个面向招投标场景的 Web 应用，覆盖标书导入到应答生成的全流程。系统自动完成：

| 步骤 | 功能 | 输出 |
|------|------|------|
| 1. 导入 | 上传招标文件（PDF/DOCX），自动解析文档结构 | 结构化文本 + 章节识别 |
| 2. 提取 | LLM 提取项目名称、客户名称、截止日期等关键元数据 | `{项目名称}信息V1.md` |
| 3. 识别 | 自动定位「采购需求/技术要求」章节，排除商务/法人内容 | 技术要求章节清单 |
| 4. 应答 | 生成技术偏离表 Excel（序号/招标条款/投标应答/偏离说明） | `{项目名称}_技术偏离表.xlsx` |
| 5. 提醒 | 联动飞书日历，截止前 4 天自动创建提醒事件 | 飞书日历事件 |

### 核心价值

- **效率提升**：从手动摘抄 2-3 小时缩短到 5 分钟
- **质量保障**：LLM 按规则拆条，C 列措辞自动清洗，避免遗漏/截断
- **安全合规**：API Key 等敏感信息 AES-256-GCM 加密存储，Bearer Token 保护外部接口
- **联动生态**：飞书日历自动提醒，外部 API 可供其他系统集成

## 三、快速开始

### 3.1 环境要求

- Python 3.10+ 或 Docker
- 飞书应用（可选，用于日历提醒）
- DeepSeek API Key 或其他 OpenAI 兼容 API

### 3.2 Docker 部署（推荐）

```bash
# 1. 进入项目目录
cd bid-info-extractor

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env：填入 LLM_API_KEY、ENCRYPTION_MASTER_PASSWORD

# 3. 启动
docker-compose up -d

# 4. 访问
open http://localhost:8000
```

### 3.3 本地开发

```bash
pip install -r requirements.txt
cp .env.example .env          # 编辑填入配置
uvicorn app.main:app --reload --port 8000
```

### 3.4 首次配置

1. 访问 `http://localhost:8000/settings`
2. 确认 LLM Base URL 为 `https://api.deepseek.com/v1`
3. 填入 API Key（页面输入或 `.env` 配置）
4. 点击「测试连接」验证
5. （可选）配置飞书 App ID/Secret
6. （可选）点击「生成新 Token」创建外部 API Token


**交互说明**：
- **月历**：点击日期高亮，右侧列表同步筛选当日项目
- **统计栏**：点击「进行中/已结束/即将截止」筛选列表
- **上传**：点击或拖拽 PDF/DOCX 文件到右上角上传区
- **详情面板**：点击项目行 → 右侧滑出编辑表单 → 可修改元数据后保存

### 4.2 文档管理

`/documents` 页面提供完整的项目 CRUD：

- 拖拽上传 PDF/DOCX（最大 500MB）
- 项目表格：名称 / 客户 / 截止日期 / 状态 / 操作
- 操作入口：查看详情 / 删除项目
- 点击项目名跳转至提取结果页

### 4.3 提取结果

`/extraction/{id}` 页面提供逐步操作流程：

| 步骤 | 按钮 | 说明 |
|------|------|------|
| 1 | 🔍 提取元数据 | LLM 提取项目名/客户名/截止日期 |
| 2 | 📄 生成 Markdown | 输出 `{项目名称}信息V1.md` |
| 3 | 🔬 识别技术要求 | 定位采购需求章节（排除商务内容） |
| 4 | 📊 生成 Excel | 技术偏离表（A/B/C/D 四列） |
| 5 | 📅 创建日历提醒 | 飞书日历事件（截止前 4 天） |

### 4.4 日历事件

`/calendar` 页面展示所有已创建的飞书日历事件：

- 事件列表：项目名称 / 提醒日期 / 时间段 / 状态
- 失败事件可「重试」
- 已完成事件可「删除」

### 4.5 系统设置

`/settings` 页面配置系统运行参数：

| 配置组 | 字段 | 说明 |
|--------|------|------|
| 大模型 | Base URL / API Key / Model | 默认 DeepSeek，支持 OpenAI 兼容接口 |
| 飞书 | App ID / App Secret | 日历提醒功能的前置条件 |
| TechToExcel | 脚本路径 / 额外参数 | 外部脚本调用配置（可选） |
| API Token | 当前 Token / 生成新 Token | 外部系统调用凭证 |

**安全提示**：
- 加密状态标识显示当前存储安全级别
- 🔒 绿色 = AES-256-GCM 加密已启用（已设置 `ENCRYPTION_MASTER_PASSWORD`）
- ⚠️ 黄色 = 加密未启用（敏感信息明文存储，建议配置）

## 五、常见问题

### Q: 上传后元数据提取为空？
- 确认设置页已配置 LLM API Key
- 确认 API Base URL 可访问（默认 `api.deepseek.com/v1`）
- 标书扫描件可能需要 OCR 预处理

### Q: 技术偏离表 Excel 内容不完整？
- 系统优先使用「完整管线」（从原始 docx 定位章节→LLM 拆条）
- PDF 文件回退到「文本模式」（基于 LLM 识别的技术文本生成）
- 如需精确章节定位，建议使用 DOCX 源文件

### Q: 飞书日历创建失败？
- 确认飞书应用已获取 `calendar:calendar:write` 权限
- 确认 App ID 和 App Secret 正确
- 确认应用已发布并添加机器人到对应群组

### Q: 外部 API 如何调用？
```bash
# 先生成 Token（设置页 → 生成新 Token）
curl -H "Authorization: Bearer <token>" \
     http://localhost:8000/api/external/tasks?status=active
```

### Q: 数据存储在哪里？
- SQLite 数据库：`data/bid_info_extractor.db`
- 上传文件：`data/uploads/`
- 导出文件：`data/exports/`
- Docker 部署时通过 volume 挂载持久化
